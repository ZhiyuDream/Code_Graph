# Worklist 调查实验

这些实验测试了不依赖 LLM 做导航的确定性 worklist，以及少量 LLM 参与检索扩展的混合 worklist。

## 核心思想

不再让 LLM 决定"下一步读哪个文件"，而是：
1. 先读完 Top-K 候选文件；
2. 对每个已访问目录，在该目录内继续做局部检索；
3. 重复多跳，系统性地扩大搜索边界。

## 1. 读完所有 Top20（Read-all Top20）

**做法：** 读 Top20 池中每个文件的前 100 行。

| 指标 | 数值 |
|------|-----:|
| 完整覆盖率 | 30/50 = **60%** |
| 平均覆盖率 | 77.5% |
| 平均读取文件数 | 17.4 |

**结论：** 仅机械地读完 Top20 就比 Naive ReAct（22%）高近 3 倍。说明 ReAct 的损失主要来自过早停止，而非推理错误。

## 2. Top20 + 目录扩展（Dir-expansion）

**做法：** 在读完 Top20 后，对每个已访问目录，在该目录内用原问题 embedding 检索 top 2 个未访问文件并读取。

| 指标 | 数值 |
|------|-----:|
| 完整覆盖率 | 39/50 = **78%** |
| 平均覆盖率 | 87.3% |
| 平均读取文件数 | 25.6 |

**结论：** 目录扩展是最有效的单一操作。20 个 under-covered 问题中有 17 个可通过读取同目录其他文件恢复。

## 3. 读完所有 Top50 / Top100 / Top200

| 方法 | 完整覆盖率 | 平均覆盖率 | 平均读取文件数 |
|------|-----------:|----------:|-------------:|
| Read-all Top50 | 78% | 87.3% | 39.9 |
| Read-all Top100 | 86% | 91.0% | 75.1 |
| Read-all Top200 | 94% | 95.5% | 135.3 |

**结论：** 扩大检索池有效，但读 100/200 个文件成本高。注意：K=200 时实际平均只读了 135 个文件，因为函数块级检索去重后凑不够 200 个唯一文件。真正的文件级 Top-200 天花板是 98%。

## 4. 确定性 Worklist（Top20 + 2-hop 目录扩展）
**做法：**
- 读 Top20 池中所有文件；
- 第 1 跳：对每个已访问目录，检索并读 top 5 个未访问文件；
- 第 2 跳：对新访问的目录重复上述过程。

| 指标 | 数值 |
|------|-----:|
| 完整覆盖率 | 43/50 = **86%** |
| 平均覆盖率 | 91.0% |
| 平均读取文件数 | 50.8 |

**结论：** 与 Read-all Top100 相同覆盖率，但少读 24 个文件（32%）。说明局部目录检索比全局排名更聚焦。

## 5. 查询扩展 Worklist（Query-expansion Worklist）

**做法：** 在确定性 worklist 前，先用廉价 LLM 生成 3-5 个英文查询，检索这些查询的文件并合并到初始池。

| 指标 | 数值 |
|------|-----:|
| 完整覆盖率 | 44/50 = **88%** |
| 平均覆盖率 | 93.0% |
| 平均读取文件数 | ~55 |

**结论：** 对抽象中文问题有效。例如"设备切换"经 LLM 扩展为 "sycl device switch" 后，能召回 `ggml-sycl.cpp` 等文件。

## 6. 符号图 Worklist（Symbol-graph Worklist）

**做法：** 在目录扩展后，从已访问文件中提取高频符号，做 `find_callers` / `find_callees`，读取新发现的文件。

| 指标 | 数值 |
|------|-----:|
| 完整覆盖率 | 45/50 = **90%** |
| 平均覆盖率 | 95.0% |
| 平均读取文件数 | ~62 |

**结论：** 调用图扩展能追回跨目录的 gold 文件。当前效果最好。

## 7. 为什么确定性 Worklist 这么有效？

1. **不提前停止**：机械读完所有候选文件。
2. **利用目录局部性**：gold 文件经常与候选文件在同一目录。
3. **局部检索更聚焦**：在目录内检索比全局检索噪声小。
4. **没有 LLM 决策噪声**：不会因为"觉得够了"而停止，也不会重复搜索。

## 8. 局限

1. **不能跨太远模块**：如果 gold 文件与 Top20 完全不在同一目录，也难找到。
2. **依赖 Top20 至少命中一个相关目录**。
3. **不会做语义跳跃**：例如不会主动从"设备切换"推断到"SYCL"。

这就是为什么查询扩展（88%）和符号图（90%）能再补一部分。
